# 안정형 되기

20대 대학생·사회초년생을 위한 AI 기반 **안전 판단 훈련** 웹앱.

이 서비스는 "질문 → 답변"형 안전 챗봇이 아니라,
**상황 → 내 판단 → 변화된 상황 → 다시 판단 → AI 해석** 구조의 연속 판단 훈련이다.
사용자는 정답을 먼저 배우는 대신, 구체적 위기 상황에서 먼저 판단하고 그 판단 과정을 검증받는다.

## AI의 역할 (제한된 범위)

AI는 안전수칙의 정답을 새로 생성하지 않는다. 핵심 행동원칙·위험행동·평가 기준은
사람이 검증한 데이터로 코드에 고정되어 있다(`lib/data/scenarios.ts`). AI는 그 범위 안에서만:

1. 사용자가 입력/선택한 행동의 의미를 해석하고
2. 검증된 원칙·기준과 비교해
3. 잘한 판단과 위험한 판단을 분리해 설명하며
4. 애매하면 억지 추론 없이 "명확히 평가하기 어렵다"고 응답한다.

자유응답(freeText) 노드에서 AI는 사용자의 자연어 판단을 **행동 단위로 분해**해
구조화된 분석(`summary / goodJudgments / riskyJudgments / feedback / principleUsed / confidence`)을 반환한다.
객관식 노드는 검증된 평가를 결정론적으로 사용하고, AI는 자연스러운 설명 문장만 개인화한다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## AI 개인화 피드백 연결 (선택)

`.env.local` 파일에 아래와 같이 Anthropic API 키를 설정하면 선택에 대한 AI 개인화 설명이 활성화됩니다.

```
ANTHROPIC_API_KEY=sk-ant-...
```

키가 없거나 API 호출이 실패해도 서비스는 정상적으로 완주할 수 있습니다.
객관식은 검증된 static 피드백으로, 자유응답은 그 상황의 검증된 "판단 포인트"(evaluationCriteria)와
원칙을 보여주는 fallback으로 자동 대체됩니다.

## 시나리오 데이터 구조 (decision tree)

`lib/data/scenarios.ts`의 `scenarios` 배열에 시나리오 객체를 추가합니다.
각 시나리오는 `nodes`(판단 노드 그래프)로 구성되며, 노드는 `inputType`이 `choice` 또는 `freeText`입니다.

- `choice` 노드: `choices[]`의 각 선택지에 `next`를 지정해 **분기**를 만들 수 있습니다
  (사용자의 판단이 다음 상황을 바꿉니다). `next: null`이면 시나리오 종료.
- `freeText` 노드: `evaluationCriteria`(AI 해석 기준)와 `fallbackFreeText`를 두면,
  AI가 사용자의 자연어 판단을 행동 단위로 분해해 평가합니다.
- `implemented: true` + `startNodeId` 지정 시 실제 인터랙션이 활성화되고,
  `false`(status: "coming-soon")면 라이브러리에 "준비 중" 카드로만 노출됩니다.

## 데이터 저장

회원가입/서버 DB 없이 브라우저 `localStorage`에 학습 완료 기록을 저장합니다
(`lib/storage.ts`). 새로고침해도 진행 상황이 유지됩니다.

## 주요 화면

- `/` — 홈 (오늘의 추천, 대비 현황 요약)
- `/scenarios` — 시나리오 라이브러리 (카테고리 필터)
- `/scenario/[id]` — 인터랙티브 판단 시나리오
- `/result/[id]` — 학습 완료 화면
- `/profile` — 나의 안전 대비 (분야별 학습 현황)

## 구현 완료 시나리오 (실제 인터랙션)

1. **EP.01 — 새벽 2시, 자취방에 불이 났다** — 5개 연속 판단(자유응답 2 + 객관식 3).
   문 확인 단계에서 "바로 문을 연다"를 고르면 다음 상황이 악화되는 **분기**가 발동합니다.
2. **EP.02 — 눈앞에서 사람이 쓰러졌다** — 3개 연속 판단(자유응답 1 + 객관식 2).
   "조금 더 지켜본다"를 고르면 골든타임이 줄어든 상황으로 분기됩니다.

나머지 4개(지하철 연기, 기도폐쇄, 지진, 침수)는 라이브러리에 "준비 중"으로 노출됩니다.
